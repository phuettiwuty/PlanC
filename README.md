# KU Portal Demo

หน้าเข้าสู่ระบบต้นแบบสำหรับการออกแบบ UI เท่านั้น ยังไม่ได้เชื่อม KU ALL-Login และไม่ส่งหรือเก็บรหัสผ่านของผู้ใช้

## เปิดใน Visual Studio Code

1. เปิดโฟลเดอร์โปรเจกต์นี้ใน Visual Studio Code
2. เปิด Terminal ใน VS Code
3. พิมพ์ `npm run dev`
4. เปิด [http://localhost:3000](http://localhost:3000)

หรือกด Run and Debug แล้วเลือก **เปิด KU Portal Demo**

ไฟล์หน้าเว็บอยู่ที่ `outputs/index.html`
